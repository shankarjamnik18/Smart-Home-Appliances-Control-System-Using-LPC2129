# Smart-Home-Appliances-Control-System-Using-LPC2129
Developed an LPC2129 ARM7-based Smart Home Appliance Control System using Embedded C. Implemented UART interrupt-based control and GPIO push-button control for appliance ON/OFF operation. LEDs represent home appliances, with a mode-selection switch for UART/GPIO control. Designed and tested the complete system using Proteus simulation.
